## 2. Öğrendiğim komutlar

| Komut | Ne işe yarar |
|-------|--------------|
| `pwd` | Bulunduğum dizini gösterir |
| `ls` | Dosyaları listeler |
| `cd` | Klasör değiştirir |
| `mkdir` | Klasör oluşturur |
| `touch` | Dosya oluşturur |
| `cat` | Dosya içeriğini gösterir |
| `git status` | Git durumunu gösterir |
| `git clone` | Repoyu bilgisayara indirir |
| `git branch` | Branch listesini gösterir |
| `git checkout -b` | Yeni branch oluşturur |

## 3. Git akışı

git add Hafta1/zeynep_sukas_hafta1.md
